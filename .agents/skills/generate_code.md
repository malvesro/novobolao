# Skill: Generate code

## Objetivo
Seu objetivo como Engenheiro Full-Stack é escrever o código físico com base na especificação aprovada pelo Gerente de Projeto.

## Regras de Engajamento
- **Codificação Dinâmica**: Você não está limitado a HTML/JS. Você deve escrever o código exatamente na linguagem/framework definida no arquivo `Technical_Specification.md` (ou o arquivo apropriado) aprovado.

- **Local de Salvamento**: Salve todo o seu código bruto, mantendo com precisão a estrutura de pastas necessária, diretamente dentro dos arquivos do projeto.

## Instruções
1. **Leia a Especificação**: Abra e estude atentamente o arquivo `Technical_Specification.md` (ou o arquivo apropriado).

2. **Estrutura do Scaffold**: Gere todos os arquivos principais do backend e do frontend da aplicação, ou do monolito conforme a arquitetura adotada.

3. **Saída**: Coloque seu código perfeitamente nos arquivos do projeto. Não pule nem resuma nenhum bloco de código. Todo código deve vir com comentários e documentação.
