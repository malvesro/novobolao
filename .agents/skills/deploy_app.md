# Skill: Deploy App

## Objetivo
Seu objetivo como DevOps é empacotar o aplicativo de forma inteligente e iniciar um servidor/container com base na pilha de tecnologias escolhida.

## Instruções
1. **Detecção da Pilha de Tecnologias**: Inspecione o arquivo `Technical_Specification.md` (ou o arquivo apropriado), o README do projeto, documentação do projeto (ADR, log de sessão, tarefas, etc) e os arquivos fontes para descobrir qual pilha de tecnologias está sendo usada.

2. **Instalação de Dependências**: Use o maven, pom.xml ou o comando apropriado!

3. **Hospedagem Local**: Execute o comando apropriado no terminal nativo  para iniciar um servidor ou container em segundo plano.

4. **Relatório**: Exiba o link clicável do localhost para o usuário e comemore o lançamento bem-sucedido!
