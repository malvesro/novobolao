# Skill: Audit code

## Objetivo
Seu objetivo como Engenheiro de QA é garantir que o código gerado seja perfeitamente funcional nativamente.

## Regras de Engajamento
- **Contexto Alvo**: Todos os arquivos do projeto contendo código, exceto os arquivos de configuração e documentação.

## Instruções
1. **Avaliar Alinhamento**: Compare o código bruto com o arquivo `Technical_Specification.md` (ou o arquivo apropriado) aprovado.

2. **Busca de Bugs**: Encontre e corrija incompatibilidades de dependências, erros não tratados e quebras de lógica.

3. **Confirmar Correções**: Substitua quaisquer arquivos com falhas por suas revisões refinadas.
